Most things in opendesk work without a mouse. Press <kbd>?</kbd> anywhere in the app, outside a text box, to see every shortcut.

<Screenshot src="/guides/shortcuts/sheet" alt="The Keyboard shortcuts sheet with three lists: General, Ticket list and Ticket, each action next to its keys" />

You can also open the sheet from the account menu: click your name at the bottom of the sidebar, then **Keyboard shortcuts**.

<Screenshot src="/guides/shortcuts/menu" alt="The account menu open from the bottom of the sidebar, with Keyboard shortcuts and its ? key ringed as 1" />

<Callout type="note" title="Reading the keys">

<kbd>mod</kbd> is <kbd>⌘</kbd> on macOS and <kbd>Ctrl</kbd> elsewhere. Two keys joined by "then" are pressed one after the other: <kbd>g</kbd> then <kbd>i</kbd> means press <kbd>g</kbd>, let go, then press <kbd>i</kbd>.

</Callout>

## General

| Keys | Action |
| --- | --- |
| <kbd>mod</kbd> <kbd>k</kbd> | Command menu: search tickets, contacts, articles and settings |
| <kbd>mod</kbd> <kbd>j</kbd> | Ask Ollie (in a ticket's reply box, Ollie drafts a reply instead) |
| <kbd>/</kbd> | Search tickets |
| <kbd>c</kbd> | New ticket |
| <kbd>?</kbd> | Keyboard shortcuts |
| <kbd>g</kbd> then <kbd>i</kbd> | Go to inbox |
| <kbd>g</kbd> then <kbd>m</kbd> | Go to my tickets |
| <kbd>g</kbd> then <kbd>t</kbd> | Switch team, when the workspace has teams |
| <kbd>g</kbd> then <kbd>c</kbd> | Go to contacts |
| <kbd>g</kbd> then <kbd>k</kbd> | Go to knowledge base |
| <kbd>g</kbd> then <kbd>r</kbd> | Go to reports |
| <kbd>g</kbd> then <kbd>w</kbd> | Go to the wiki |
| <kbd>g</kbd> then <kbd>s</kbd> | Go to settings |
| <kbd>b</kbd> | Toggle sidebar |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>1</kbd> to <kbd>9</kbd> | Open workspace 1 to 9 |

## Ticket list

| Keys | Action |
| --- | --- |
| <kbd>j</kbd> | Next ticket |
| <kbd>k</kbd> | Previous ticket |
| <kbd>enter</kbd> | Open the focused ticket, unless a button or link has the focus: then <kbd>enter</kbd> presses it |

| <kbd>e</kbd> | Solve the focused ticket |
| <kbd>r</kbd> | Open the focused ticket and reply |
| <kbd>esc</kbd> | Close ticket or clear selection |

## In the reply box

- Type <kbd>/</kbd> to insert a [saved reply](/guides/saved-replies-and-views/), and <kbd>@</kbd> in a note to mention a teammate.
- <kbd>mod</kbd> <kbd>j</kbd> asks Ollie to draft a reply. Outside the reply box the same keys open Ollie.
- <kbd>enter</kbd> picks the highlighted item in those lists, <kbd>esc</kbd> closes them.
- A click in a link places the cursor to edit it; <kbd>mod</kbd> click opens it in a new tab, to check where it goes before sending.
- Single-key shortcuts are paused while you type, so <kbd>r</kbd> or <kbd>e</kbd> in a message is just a letter.

</Fold>

## In the command menu

Use the arrow keys to move to a ticket, contact, article or page and <kbd>enter</kbd> to open it, or <kbd>mod</kbd> <kbd>enter</kbd> to open it in a new tab with the menu left open. Results are links, like the rows of a ticket list and your notifications, so a right click, a <kbd>mod</kbd> click or a middle click opens them in a new tab too.

</Fold>

## In the wiki

On a [wiki](/guides/wiki/) page:

| Keys | Action |
| --- | --- |
| <kbd>/</kbd> | Block menu, at the start of a line |
| <kbd>[[</kbd> | Link a page |
| <kbd>@</kbd> | Mention a teammate, a page, a date, a contact or a ticket |
| <kbd>#</kbd> | Mention a ticket, by number or words |
| <kbd>:</kbd> | Emoji |
| <kbd>space</kbd> | Ask Ollie to write, on an empty line |
| <kbd>mod</kbd> <kbd>j</kbd> | Ask Ollie about the selected text |
| <kbd>mod</kbd> <kbd>s</kbd> | Save now |
| <kbd>mod</kbd> <kbd>shift</kbd> <kbd>;</kbd> | Page panel: outline, links, graph, comments and info |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>m</kbd> | Comment on the selected text |
| <kbd>mod</kbd> <kbd>b</kbd>, <kbd>i</kbd>, <kbd>u</kbd> | Bold, italic, underline |
| <kbd>mod</kbd> <kbd>shift</kbd> <kbd>s</kbd> | Strikethrough |
| <kbd>mod</kbd> <kbd>e</kbd> | Inline code |
| <kbd>mod</kbd> <kbd>shift</kbd> <kbd>h</kbd> | Highlight |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>0</kbd> | Text |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>1</kbd> to <kbd>3</kbd> | Heading 1 to 3 |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>4</kbd> | To-do list |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>5</kbd> | Bulleted list |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>6</kbd> | Numbered list |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>7</kbd> | Toggle list |
| <kbd>mod</kbd> <kbd>alt</kbd> <kbd>8</kbd> | Code |
| <kbd>mod</kbd> <kbd>enter</kbd> | Tick or untick a to-do; in a comment, send it |
| <kbd>mod</kbd> <kbd>d</kbd> | Duplicate the block |
| <kbd>mod</kbd> <kbd>shift</kbd> <kbd>↑</kbd> or <kbd>↓</kbd> | Move the block up or down |

In the wiki's sidebar, the arrow keys move between pages, <kbd>→</kbd> and <kbd>←</kbd> open and close a page's subpages, and <kbd>enter</kbd> opens one. <kbd>alt</kbd> with an arrow key moves the focused page: up or down among its neighbours, <kbd>→</kbd> inside the page above, <kbd>←</kbd> out a level. In a database's calendar, <kbd>alt</kbd> and an arrow key moves the focused row a day or a week. In the graph, the arrow keys move it, <kbd>+</kbd> and <kbd>-</kbd> zoom and <kbd>0</kbd> fits it.

Markdown works as you type, too: see [Markdown shortcuts and paste](/guides/wiki/#markdown-shortcuts-and-paste).

## In menus and pickers

Use the arrow keys to move through a menu or picker, <kbd>enter</kbd> to choose, and <kbd>esc</kbd> to close without changing anything. In a picker with a search box, type to narrow the list.

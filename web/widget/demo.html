A host page for testing the opendesk chat widget against an in-memory backend that simulates the AI agent (live streaming, tools, an action card, ratings and a handoff).

Appearance: ?key= wk_brand (brand colour), wk_left (left, offsets), wk_label (label launcher), wk_round (round corners), wk_square, wk_dark / wk_light (forced theme), wk_email (email capture), wk_human (no AI agent), wk_topics (topics), wk_closed / wk_offline (closed, default or own offline message), wk_press (another brand). ?od_closed closes any of them, ?od_lang=ar for a language, ?od_open=1 to open it.

The agent: tap a suggestion, or ask about an order with a number and street ("Send order #4821 to 22 Baker Street") for a tool step and an action card, SSO for an answer with sources, or a person for a handoff. Hover a reply to rate it. Helpers: ?od_demo=thread, send, order, handoff.
